# 双平台独立运行与资料互通

状态：设计约束，尚未实现 macOS 适配或跨平台导入工具；本阶段不要求 macOS 实测。

## 运行模型

Windows 和 macOS 分别运行完整的本地 CLI 与浏览器 Workbench，各自拥有本机工作区、配置和安装环境。两台机器可以互不在线，不要求发现、连接或通信，也没有中心服务、多端同步或跨机器并发写入目标。

Workbench 浏览器连接本机回环地址；启动器与本机服务交换认证和控制信息属于同机进程间通信。将这部分平台实现隔离，是为了在各操作系统保持同样的启动、认证、停止语义，并不增加机器之间的通信能力。

## 共享规则与平台实现

Project/Task/Run 的身份、字段、状态检查、阅读入口与导入校验由共享 core 维护。后续实现应把真正变化的平台能力集中在少量内部接口，调用方只传结构化目标，不拼装 shell 命令。不提前引入插件框架或多存储后端。

| 能力 | 当前 Windows 实现 | 后续 macOS 实现应满足的接口语义 |
|---|---|---|
| 工作区写入互斥 | core 的 Windows mutex | 同一工作区的本机互斥，冲突明确失败，退出后可恢复；不扩展为跨机器锁 |
| 进程与实例身份 | PID、创建时间、用户 SID | 校验当前用户与具体进程实例，不能只凭 PID 或端口决定激活/停止 |
| 本机认证与控制 | 当前用户受限命名管道 | 本机受限控制通道，例如权限受限的 Unix socket；一次性令牌不进入日志或公开配置 |
| 应用打开 | WindowsOpener | 浏览器、文件与目录的结构化打开；应用缺失返回明确能力错误 |
| 安装与入口 | runtime 内 venv 和 cmd | 本机重建环境及启动入口；业务包不依赖原源码 checkout 或全局配置 |
| 路径与文件操作 | Windows 路径、原子替换、链接检查 | 解析平台路径，限制越界与链接穿越，保持原子写入/失败保留语义 |

上述表格描述未来实现的责任；当前业务代码仍含 Windows 专属实现，不能仅凭这份文档宣称 macOS 已可用。接口提取随实际适配一起实施，并以共同的行为测试检验；不为设计文档添加空适配器。

## 资料与本机状态

资料互通采用显式导出包和导入动作；用户可自行复制介质，不要求 DUMMYSYS 传输文件。

| 内容 | 导入目标 |
|---|---|
| 选定的知识正文、项目/Task 文档与引用附件 | 随资料迁移，校验引用和内容哈希 |
| Project/Task/Run 的逻辑 ID、编号、状态及历史来源 | 保留身份和语义，不因换机器重建 ID |
| 选定的 Run 原始结果与证据 | 随声明的范围迁移；未包含的资源明确标记，不把缺失证据记为完整 |
| Repo 逻辑关联 | 保留 repo_id 与相对范围，目标机重新绑定 checkout |
| 工作区绝对路径、应用路径、服务器连接凭据 | 不作为可用绑定直接导入；目标机显式配置，凭据不进入通用资料包 |
| Python 环境、可执行文件、浏览器用户数据、锁、进程/会话状态、缓存 | 不随资料迁移，在目标机重新生成 |
| Operation 写入/恢复日志 | 属于原机器操作现场，不在目标机重放；需保留时只作历史证据 |

runtime 同时容纳持久证据与可重建状态，不能把整个 runtime 都忽略，也不能整体复制。原始证据中的历史机器信息保留其来源含义，不伪装成目标机当前配置。

## 导入契约草案

1. 导出前确认所选范围没有进行中的写入或待恢复 Operation，生成一致的资料清单。运行中的工作必须明确停止或作为不完整快照处理，不伪造完成状态。
2. 导出包声明独立的数据格式版本、对象身份、包内相对路径、文件哈希与未打包的外部引用；数据格式版本与产品发行版本分别表达。只接受明确支持的格式，未知版本保留原包并拒绝导入，不承诺自动跨版本升级。
3. 首次实现优先导入新工作区。新工作区生成自己的本机实例身份，Project/Task/Run ID 随资料保留；导入到已有工作区时遇到 ID 冲突拒绝覆盖，不默认合并或重复创建。
4. 不在导入时执行包内代码。验证目录穿越、绝对路径、符号链接/目录联接和解包大小；检查 Windows 保留名称、长度、大小写碰撞与 Unicode 名称差异。无法无损表示的路径明确拒绝并给出映射清单，不静默改名。
5. 当前文件中的工作区绝对引用通过已声明的来源根和相对路径映射到目标；不得对正文任意字符串作全局替换。稳定引用保持，外部 Repo/应用位置要求重新绑定；无法解析的引用列入报告。
6. 先在目标 runtime 暂存、校验，再经 core 受管操作生效。失败保留原包、暂存清单与恢复信息，不覆盖已有资料、不删除整个目标目录。
7. 导入后重建目录投影与阅读入口，核对 ID、文件哈希、引用和证据完整性。只有相应检查通过，才报告该次导入成功。
